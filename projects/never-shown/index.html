I Never Showed It the Task

Single-skill phone clips → RL teacher → a VLA that follows multi-step instructions.

Ayush Deshmukh · Isaac Lab, PPO, SmolVLA

Code Play with it

I filmed myself doing single skills (push, pick up, put down), turned the clips into a reward, trained an RL teacher in simulation and distilled it into a vision-language-action model. It gets one sentence with six commands and does all six in order in 40 of 100 runs, though it never trained on more than two.

Pipeline

  1. Film skillsOne skill per clip.
  2. Infer the rewardFrom the object's tracked path.
  3. RL teacherPPO, 16,384 envs.
  4. Distill into a VLACameras + sentence.
  5. ComposeLonger tasks, never demonstrated.

Results

40%6 commands, all in order
81%4 commands, all in order
0%8 commands, the next bar

The clips

43 phone clips, one skill each. ArUco markers track the objects, not my hand.

Keeping its place

The camera image alone doesn't say which step it's on. So the model has an extra "done" output, and when it fires, "(done)" is written into the sentence it reads next:

pick up the cube(done), then put the cube on the cylinder(done), then pick up the cube, then put the cube on the target

What didn't work

  • Fine-tuning SmolVLA directly on single skills: 0 on every combined task.
  • Imitating raw PPO actions: too jittery to learn. A low-pass filter on the teacher's arm fixed it.
  • A step counter instead of "(done)" marks: 5 of 100 on six commands.
